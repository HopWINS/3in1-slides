# 3in1 interactive talk — revision 23

A 20-slide HTML presentation of **3in1: Multi-tone Joint Powering, Clocking, and Communication for Passive IoT** by Ruirong Huang and Renjie Zhao, SenSys 2026.

[Paper](https://doi.org/10.1145/3774906.3800458)

## Present

Open `index.html`, or use the GitHub Pages deployment. No build step or internet dependency is required for the presentation itself.

- Arrow keys or Space: navigate
- O: slide overview
- P: pause or resume animation
- F: fullscreen

Scientific animations use the paper's multitone and rectifier equations. Model amplitudes are normalized; plotted measurements are labeled separately. The deployed HTML embeds all scripts, styles, fonts, and images. The original modular source remains in the local slide workspace. KaTeX is included with its MIT license in `KATEX_LICENSE`; the outlined Audiowide lab lettering is covered by `AUDIOWIDE_LICENSE`. The title-page decoded data is an ideal coherent phase decision, not a measured BER trace. The simplified RFID inlay drawing references the [Avery Dennison AD Dogbone](https://rfid.averydennison.com/en/home/product-finder/dogbone.html).

This revision includes the updated dark-background JHU/HopWINS marks, Department of Computer Science affiliation, balanced body layouts, a closing slides QR code, and slide 10's synchronized empty-battery cue. The battery is a qualitative supply-budget illustration, not a simulated state of charge or a measured shutdown threshold. The bookend JHU mark is the requested larger-shield presentation composition using the original outlined artwork; it is not an alternative official university lockup.
